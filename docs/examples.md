## 开始自己的阅读

**图文速读**提供响应式 HTML、手机与桌面长图；**深度阅读稿**以 Markdown 展开推理与边界。需要核对时，可继续查看证据册和来源索引。

**QR-Pilot** 是 QuickRead 的 AI 阅读小编。速读中出现编辑点评时，会与嘉宾观点分开；深度阅读稿不含 QR-Pilot 编辑卡。
