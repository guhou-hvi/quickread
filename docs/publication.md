# QuickRead v0.1.0 发布说明

作者：**guhou-hvi**。项目提供通用代码、提示词、模板与使用文档，通过 Agent 将本地文字材料整理成阅读成品。

[项目仓库](https://github.com/guhou-hvi/quickread) · [v0.1.0 Release 与源码 ZIP](https://github.com/guhou-hvi/quickread/releases/tag/v0.1.0) · [反馈与授权申请](https://github.com/guhou-hvi/quickread/issues)

## 版本内容

- 输入本地 SRT、VTT、TXT、MD；字幕获取、音视频下载与语音转写由外部工具完成。
- 生成图文速读与深度阅读稿：速读包括 HTML、手机长图和桌面长图，深度稿为 Markdown。证据册与来源索引辅助核对。
- 通过分阶段处理、资料核验和独立多角色审查，区分原文事实、发言者观点、补充背景与 QR-Pilot 编辑点评。
- 提供原创演示文章及两张实际成品模块截图，展示两种成品与原文回查。真实案例只保留名称、方法说明和原链接。

## 运行与验证范围

当前运行路径为 Windows、Node.js ≥24、Edge/Chrome，以及能够读写文件、执行命令、检索和独立审查的 Agent。安装、准备文字材料和对话启动步骤见 [快速开始](getting-started.md)。空案例目录从 `QR-0001` 开始。

随包原创演示由 AI 协助起草，用于验证整理、来源定位与导出流程；不提供节时比例或固定处理耗时的结论。内容整理与独立审查由 Agent 完成，命令行工具负责解析、校验及渲染。验证记录不替代使用者对成品的审阅。
