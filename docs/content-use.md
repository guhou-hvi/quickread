# 素材使用与公开分享

QuickRead 整理本地文字材料。取得字幕、完成 AI 整理、免费分享或注明出处，并不自动取得原作品的复制、改编或网络传播许可。个人学习和公开发布应分别判断。[《著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)

本公开源码包使用原创演示文章及其两张实际成品截图，演示由 AI 协助起草，用于说明两种阅读成品与来源回查。真实采访、讲座和辩论仅保留名称、整理方式及原链接，完整案例、原字幕和第三方截图保留在作者工作库。

宣传图卡属于另行管理的材料，其中的真实案例节选和封面拼图不随源码包分发。其素材记录保留实际来源和许可状态，发布前仍需核验具体使用依据；不会因为源码包改用原创示例而自动获得许可。

如果需要发布完整案例，优先使用自己的作品、明确许可允许的材料，或取得覆盖整理和公开传播的授权。涉及封面摄影、人物肖像及标志时分别核查，打码不能一并解决相关权利问题。[《民法典》第 1018—1020 条](https://tjca.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_20cf1a2e1b854924b5caa744c8045d1f.html)

复用 Winston 讲座前，应阅读 [MIT OCW 条款](https://ocw.mit.edu/pages/privacy-and-terms-of-use/)及具体内容的第三方例外。当前公开文档只中性介绍案例名称、整理方式和原链接，不使用机构名称或标志暗示推荐、合作或背书。

公开工具代码、第三方案例内容和字体文件属于不同的许可范围。给代码选择许可证，不能同时替第三方素材授予许可。若计划公开长篇未授权整理稿或商业化，建议让知识产权律师审核具体使用方案。

## 分享文件前的检查

- 检查 `inbox/`、`cases/*/input/`、完整 `output/`、`work/` 证据、`legacy/` 及旧宣传包；公开内容按明确清单选择。
- 公开版从审核后的文件清单建立新历史，不继承原工作库索引、提交或本地完整案例；后续分享仍需复核实际提交内容。
- 旧版宣传目录含完整长图，应留在本地归档，不随当前宣传包上传。
- 核对作者、作品名称、原链接和许可证条件；保留必要的授权记录。来源标注不能代替许可。
- 确认 GitHub remote 的公开访问状态，核对最终下载包及其隐藏图片、备注、附带文件。

第五版宣传封面保留用户提供的视频时长拼图，原画面来源及使用状态记录在工作库素材清单，仍需推广发布前核验。它不随本源码包分发。源码发布与宣传发布分别执行；源码版本内容见 [发布说明](publication.md)。
