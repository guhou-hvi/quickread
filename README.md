# QuickRead v0.1.0

简体中文 · [English](README.en.md)

**先抓住长内容的关键信息，再决定哪里值得细看。**

QuickRead 把本地字幕、音视频转写稿和文章，整理成**图文速读与深度阅读稿**。AI 阅读小编 **QR-Pilot** 帮你梳理主题，也留下重要判断的理由、条件和来源。

[先看示例](docs/examples.md) · [开始使用](docs/getting-started.md) · [调整阅读偏好](docs/customization.md)

## 为什么做这个项目

看到一场很想看的专访，点开：好几个小时。

好，先收藏。至于什么时候看……我常常就停在这一步。

所以，我想把这些内容变得更容易开始读。扫一遍找到主线，跳到关心的问题，遇到值得细看的地方再回去听。零碎时间，也能用来读一场长谈。

## 🧭 我希望留下的，是判断的理由

读完之后，我还想知道：他为什么这么判断？考虑了哪些条件？几件事之间有什么联系？

QuickRead 围绕主题组织内容，把观点、理由和重要限定放到一起。发言者的判断保留归属，补充背景另列出处，需要时可以回到来源核对。

QR-Pilot 是这个项目里的 AI 阅读小编。你提供本地材料，Agent 按仓库规则分阶段整理、核验和独立审查，最后把阅读文件保存在本地。

## 一份材料，两种阅读成品

| 想怎么读 | 对应成品 | 文件形式 |
| --- | --- | --- |
| 先看主线，抓住关键判断 | 图文速读 | 响应式 HTML、手机长图、桌面长图 |
| 把理由、背景和限定读透 | 深度阅读稿 | Markdown |

需要核对时，还有来源索引和证据册。速读如有 QR-Pilot 编辑点评，会与嘉宾观点分开；深度稿采用第三人称观察者叙述，不含编辑卡。

当前默认成品为**简体中文**。可以先用下方原创演示跑通流程，再换成自己想读的材料。

## 🛠️ 开始第一份阅读

准备好 **Windows、Node.js ≥24、Edge 或 Chrome**，以及能读写文件、运行命令、检索资料、在独立上下文中完成多角色审查的 AI Agent。模型接入与使用费用取决于你的 Agent 环境。

克隆项目，在根目录安装依赖：

```powershell
git clone https://github.com/guhou-hvi/quickread.git
cd quickread
node --version
npm ci
```

也可以下载 [v0.1.0 Release](https://github.com/guhou-hvi/quickread/releases/tag/v0.1.0) 的源码 ZIP，解压后执行 `npm ci`。Release 保留首发快照，仓库首页会继续更新介绍文档。

1. 在 Agent 中打开项目，让它读取 `AGENTS.md`。
2. 放**一份**本地 `SRT`、`VTT`、`TXT` 或 `MD` 到 `inbox/`。
3. 对 Agent 说：

```text
处理 inbox
```

有原始页面链接时，一并提供，方便回源核验；如果放了多个文件，请指明先处理哪一份。成品保存在分配到的案例目录下的 `output/`，包括阅读页面、手机长图和深度稿。

也可以从随包演示开始，直接说：

```text
处理 examples/reading-experiment.md；这是原创演示材料，没有公开来源链接。
```

完整环境、外部文件用法和交付位置见[上手说明](docs/getting-started.md)。新目录中的第一个案例从 `QR-0001` 开始。

## 手头只有音视频，也可以先准备文字

- **已有字幕**：导出字幕，或复制平台提供的文字稿。
- **已有音视频**：把有权处理的文件交给 Buzz 等语音转写工具，再导出文字。
- **已有文章**：保存为 UTF-8 TXT 或 Markdown，保留标题和来源链接。

有时间定位时优先 SRT／VTT。转写后抽查人名、数字、术语、否定词和说话人。获取音视频与转写属于外部准备步骤，QuickRead 当前接收本地文字文件。Bilibili Obsidian Clipper、YouTube 文字稿与 Buzz 的用法见[材料准备](docs/getting-started.md#准备字幕或正文)。

## 改成适合自己的版本

你更关心技术细节，还是产品决策？可以直接告诉 Agent，例如：

> 我更关心产品决策，请突出目标、约束、选择理由与代价；保留关键限定和来源依据。请用现有提示词与配置，把这个偏好应用到下一个案例。

[个性化指南](docs/customization.md)列出了关注点、详略和版式的具体指令与修改入口。
